# 昔涟聊天界面 · 第一版设计预览

本目录保留设计确认前的独立交互原型，不由正式 `AI/src/` 引用，不会被 Vite 或 Electron 安装包包含。用户已确认此版气泡和侧栏设计，正式实现位于 `AI/src/App.vue`、`AI/src/chatShell.css`，装饰副本位于 `AI/public/xilian-bubble-corner-v1.png`。

## 设计调整

- 会话侧栏改为按内容排列的浮动卡片，当前只展示一条真实场景示例，避免用虚构的历史记录填满留白。
- 顶栏按钮可完全隐藏/恢复侧栏，聊天区域随之重新居中，窄窗口下作为抽屉使用。
- 聊天气泡限制行宽，采用基于昔涟素材新生成的玫瑰、渐变羽饰和短缎带边角装饰，预留文字区域；详见 ASSET_NOTES.md。
- 输入框缩窄居中，采用独立占位文案，只保留一处快捷键说明，保留按住说话入口。
- 继续使用现有昔涟壁纸、头像与粉紫配色，支持深浅主题。

## 本地查看

在本目录执行 `node preview-server.cjs`，打开终端给出的本机地址。可以切换侧栏、深浅主题，以及输入预览消息。语音、天气和通话按钮只说明后续接入位置，不打开麦克风或请求真实后端。

预览中的天气对话用于排版展示，不代表实际天气查询结果。背景使用现有壁纸的高清静态首帧；正式接入时继续沿用当前 Spine 动态壁纸。
